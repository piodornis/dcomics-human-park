# Mobiler Bildschirm v4

EXPLORATION / Technik PROPOSAL. Eingebautes ImageGen. Geometrische Leitquelle: vom Autor positiv bestätigtes Konstruktionsblatt v1; v3 ausschließlich Material-/Stilreferenz. Keine automatische APPROVED-/LOCKED-Freigabe.

Vier orthografische Ansichten. Sichtprüfung: Korpus und Schulterabstände visuell weitgehend gleich, Landscape verdeckt vorne Schultern und Oberarme; Rückansichten zeigen unveränderten Schulterträger. Displaykanten wechseln zwischen Hoch-/Querformat annähernd ihre Längen. Vorne Fußspitzen, hinten Fersen. Genauigkeit ist illustrativ, kein maßhaltiger CAD-Nachweis. Tiefe, Drehfreiraum und Faltung bleiben offen.

Lokal im Ausgabeordner gespeichert. Vorversionen erhalten; keine Änderung der SELECTED-Büroserie oder des Story-Kanons.
