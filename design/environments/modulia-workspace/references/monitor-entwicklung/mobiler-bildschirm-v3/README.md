# Mobiler Bildschirm v3

EXPLORATION / technische Details PROPOSAL. Eingebautes ImageGen; lokale Ableitung von v2.

Autorenkorrektur: In Landscape muss auch der linke Arm des Bots (im Bild rechts) am hinteren stationären Bot-Träger sitzen. Ergebnis zeigt nun eine cremefarbene auskragende Halterung hinter dem Display statt eines unmittelbar an der Displaykante sitzenden Schultergelenks. Füße weiterhin nach vorne. Der Anschluss zur zentralen Rückensäule bleibt durch das Display verdeckt; die Ansicht ist kein vollständiger Konstruktionsnachweis. Frühere offene Punkte zu Seitenverhältnis und Faltmechanik bleiben bestehen. Vorversionen erhalten, keine Änderung des Projektkanons oder der SELECTED-Büroserie.
