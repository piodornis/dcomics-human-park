# Modulia – zwei mobile Monitore auf dem Schreibtisch

EXPLORATION / Ausstattung PROPOSAL. Eingebautes ImageGen. Raumquelle: modulia-workspace-01; Gerätequelle: mobiler-bildschirm-v4. Zwei Geräte ersetzen die alten Monitore: links Portrait, rechts Landscape. Füße auf Arbeitsplatte, Arme am rückwärtigen Korpus. Ein fälschlich sichtbares Landscape-Schultergelenk gezielt korrigiert.

Sichtprüfung: zwei Geräte mit jeweils zwei Füßen, kein konventioneller Standfuß, Modulia am rechten Bildschirm. Bildschirmgrößen, Körperproportionen und Perspektive bleiben illustrativ; keine metrische Einbauprüfung. Original 01 dient hier nur der Nutzungsprobe; ältere Raum-/Schattendetails werden dadurch nicht erneut ausgewählt. Bisherige SELECTED-Serie unverändert. Lokal im Ausgabeordner gespeichert, noch nicht im Projekt-Repo.
