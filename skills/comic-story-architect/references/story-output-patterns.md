## Series or volume arc

```markdown
# [Arc title]

## Story objective
[What this arc changes or resolves.]

## Relevant CANON
- ...

## Central dramatic question
...

## Starting state
...

## Major phases

### Phase 1 — [name]
**Function:** ...
**Key movement:** ...
**Character impact:** ...

### Phase 2 — [name]
...

## Character arcs
### [Character]
Start -> pressure -> decisive choices -> end state

## Relationship movement
- ...

## Setups and payoffs
| Setup | Payoff | Status |
|---|---|---|
| ... | ... | PROPOSAL |

## CONFLICT
- ...

## OPEN
- ...
```

## Option comparison

When the user needs alternatives, prefer a concise comparison:

```markdown
## Option A — [name]
**Core idea:** ...
**Strength:** ...
**Risk:** ...
**Canon impact:** ...

## Option B — [name]
...

## Recommendation
[Explain which option best matches the currently established goals, without promoting it to canon.]
```

## Story impact summary

After a substantial proposal, use when helpful:

```markdown
## Downstream impacts

### Characters
- ...

### Relationships
- ...

### Timeline
- ...

### Future issues
- ...

### Canon review needed
- ...
```
