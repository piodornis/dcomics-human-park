## 1. Establish authority

Before drafting, identify which source controls the current issue structure.

Typical precedence when the project does not define another rule:

1. explicit current user instruction
2. approved issue outline
3. approved synopsis
4. accepted story-arc material
5. current canon and character state
6. exploratory notes

Do not infer approval solely from file existence.

## 2. Build a scene map

Translate the outline into scenes before writing detailed panels.
For each scene identify:

- purpose
- location
- characters
- entering state
- central pressure
- change or turn
- exit state
- setup/payoff responsibilities

If a scene has no clear purpose, do not remove it silently. Flag it or propose a merge.

## 3. Allocate pages

Estimate page weight according to dramatic importance.

Give more space to:

- emotional turning points
- reveals
- action that must remain legible
- complex relationship shifts
- major visual moments

Compress:

- routine transitions
- repeated information
- logistical actions with no dramatic value

Treat page count as a production constraint when the user or project specifies one.

## 4. Allocate panels

Use panel count to control rhythm rather than as a rigid template.

Typical tendencies:

- 1–3 panels: scale, impact, emotion, spectacle
- 4–6 panels: standard scene progression
- 7+ panels: dense conversation, compressed time, rapid beats

These are tendencies, not rules.

## 5. Write action for an artist

Describe what is visibly happening and what must be understood.

Prefer:

`B-21 blocks the doorway with the maintenance cart while B-73 reaches past him toward the failing control panel.`

Avoid prose that cannot be drawn directly unless it is clarified through visible behavior, caption, or context.

Do not overload action text with literary interiority.

## 6. Write dialogue for balloons

Keep individual dialogue units concise enough to coexist with art.
Break long speeches only where rhythm and character justify it.

Check whether the line:

- sounds like this character
- changes the scene
- reveals useful information
- creates or releases pressure
- repeats visible information unnecessarily

Use silence when it carries more weight than explanation.

## 7. Preserve beat causality

Each major beat should follow from prior action, choice, information, or pressure.
Avoid coincidence as a transition unless deliberately part of the story.

When a beat only works by violating established motivation, report a conflict rather than disguising it with dialogue.

## 8. Track issue state

At the end of the draft, note meaningful changes in:

- character knowledge
- goals
- injuries or equipment
- relationships
- location state
- world state
- active mysteries
- setups/payoffs

These notes support Canon Guardian and Continuity Reviewer handoff.

## 9. Revision modes

### Dialogue pass
Preserve action and structure unless needed for clarity. Focus on voice, brevity, subtext, rhythm, and exposition.

### Pacing pass
Preserve issue intent. Adjust page/panel distribution, scene compression, and page turns.

### Continuity pass
Preserve story intent. Fix local inconsistencies that do not alter canon; flag larger ones.

### Full script revision
Re-evaluate scene map, page allocation, dialogue, and continuity while preserving accepted issue architecture unless changes are explicitly approved.
