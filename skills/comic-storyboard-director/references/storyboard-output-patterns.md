## Status note pattern

When storyboard work exposes non-visual issues:

```markdown
## CONFLICT
The script places Character A in the room, but the prior issue ends with A leaving the facility.

## OPEN
The location file does not establish whether the control room has an exterior window.

## PROPOSAL
Use a reflection in the glass rather than a new camera position to preserve the reveal while keeping the established room layout.
```
