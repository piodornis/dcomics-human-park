# Canon Review Report Guidance

Keep reports actionable and evidence-based.

## Focused review

Lead with the result. If no contradiction exists, say so clearly and list any meaningful open questions or inferences.

For each conflict, name the two incompatible claims and their sources. Avoid vague statements such as "this may conflict with canon" without explaining why.

## Repository-wide audit

Include coverage so the creator can see which project areas were actually inspected.

Group findings by severity first, then by domain when useful.

Recommended order:

1. Blocking conflicts
2. Major conflicts
3. Minor conflicts
4. Notes and ambiguities
5. Open canon points
6. Downstream impact

## Resolution options

Offer multiple plausible options when possible. Keep each option explicit about what would change.

Do not present one option as canonical unless the creator selects it.

## Clean audit

If no conflicts are found, still report:

- reviewed scope
- any areas not available for review
- notable open questions
- high-confidence inferences only when useful
